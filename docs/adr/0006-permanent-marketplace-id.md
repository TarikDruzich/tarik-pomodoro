# Permanent id `larissa04alves.omadoro`

The Omarchy marketplace treats the id as a permanent identifier: a listed,
retired or renamed id never becomes available again. The repository and
plugin belong to larissa, so the id uses her namespace. Once submitted, the
only way to change the plugin name is a new listing with a new id, which
loses the history, hearts and State directory of existing installations.
We decided to fix the id before the first submission and not revisit it.
